# 평가 기준 대응 전략

공식 배점은 창의성 25점, 업무 현안 적합성·실현가능성·활용성 각 20점, AI 활용 적절성 15점이다. 따라서 화려한 모델 설명보다 문제 증거, 차별화된 업무 흐름, 구현·검증 계획, 도입 효과가 균형을 이뤄야 한다.

| 기준 | 반드시 보여줄 증거 | 피할 것 |
|---|---|---|
| 업무 현안 적합성 | 사용자, 현재 단계, 반복 빈도, 실패 비용, 현재 해결법 | 출처 없는 시장 규모와 막연한 불편 |
| 창의성·독창성 | 기존 흐름과 제안 흐름 비교, 핵심 차별점 | 범용 챗봇에 이름만 바꾸기 |
| AI 활용 적절성 | 입력·모델 역할·출력·사람 검토 지점 | 규칙 기반으로 충분한 일을 AI라고 포장 |
| 실현가능성·구체성 | 최소 데이터, 아키텍처, 보안, 단계별 구현, 검증 지표 | 내부 데이터와 API가 당연히 있다고 가정 |
| 활용성·기대효과 | 측정법, 적용 부서, 확장 조건, 실패 시 안전장치 | 검증 근거 없는 절감률 단정 |

## 권장 제안 흐름

1. 실제 업무 한 장면과 문제
2. 현재 방식의 병목과 위험
3. 제안하는 AI 보조 흐름
4. 입력→처리→근거가 있는 출력→사람 승인
5. 최소 프로토타입 또는 화면 흐름
6. 구현 단계, 데이터·보안·오류 대응
7. 효과를 검증할 지표와 확산 범위

## 팀 내부 100점 사전평가

제출 전 공식 기준 그대로 100점으로 두 명 이상이 독립 채점한다. 15점짜리 AI 설명을 늘리느라 85점짜리 업무·실현·효과 근거가 약해지지 않았는지 확인한다.

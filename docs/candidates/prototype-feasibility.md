## 3. 분야별 권장 경로

아이디어는 이슈 #7(현장 문제)과 #8(아이디어 비교) 결과로 정해진다. 어느 분야가 되더라도 다음 매핑을 바로 적용한다.

| 공모 분야(SRC-001) | 권장 경로 | 데모 입력 | AI 역할 | 사람 승인 지점 |
|---|---|---|---|---|
| 설계·엔지니어링 | C (선택적으로 B 추가) | 합성 DXF 도면 또는 계산서 텍스트 | 레이어·객체·주석 추출 후 누락·불일치 후보와 근거 정리 | 엔지니어가 지적 항목별 승인·기각 |
| 시공·품질관리 | D | 합성 현장 사진·작업기록 | 분류, 위험 후보, 조치안 초안 | 현장 담당자가 조치안 확정 |
| 업무 혁신(공통) | D | 공개 매뉴얼·회의록 샘플 | 근거 문단이 표시된 검색·초안 | 작성자가 초안 수정·승인 |

공통 원칙(SRC-004 시사점 반영): AI 출력에는 원문 근거, 사용한 기준·버전, 검토자, 승인·수정 이력을 남긴다. AI는 판단을 대체하지 않고 검토 우선순위와 근거 정리를 돕는다.

## 4. 최소 데모 사용자 경로

```text
1. 샘플 파일 선택 (합성 DXF / PDF / 사진, 저장소에 포함)
2. 규칙 기반 전처리 (ezdxf·pymupdf로 객체·문단 추출, AI 없이 동작)
3. AI 처리 (추출 결과 + 기준 문서 → 후보 목록, 각 항목에 근거 위치 첨부)
4. 검토 화면 (항목별 승인/기각/수정, 검토자 이름 입력)
5. 결과 저장 (JSON·Markdown 보고서, 검토 로그, 사용한 모델·버전 기록)
```

- 2단계는 AI 없이도 끝까지 동작해야 한다. LLM 장애·키 부재 시 규칙 기반 결과만으로 데모가 멈추지 않는다.
- 3단계 입력은 샘플 데이터로 한정한다. 실제 하이멕 도면·고객 자료·개인정보는 사용하지 않는다.
- 5단계 산출물이 제안서 "실현가능성·구체성" 증거와 붙임 4 첨부 화면이 된다.

## 5. 검증 환경 실측 (2026-09-29, 팀원 kijun-0108 PC)

| 항목 | 실측 결과 | 데모 활용 |
|---|---|---|
| OS | Windows 10 Home 10.0.19045 | 기본 실행 환경 |
| Python | 3.11.9, `ezdxf` 1.4.3, `pandas` 3.0.3, `pymupdf` 1.28.2, `requests` 2.34.2 설치됨 | 경로 C·D 즉시 가능 |
| Node.js | 24.16.0 | 웹 UI 대안 |
| .NET | 런타임 6.0 / 8.0 / 10.0 있음, SDK 없음, Visual Studio 없음 | 경로 A 불가(설치 필요) |
| AutoCAD | AutoCAD 2024 (R24.3) 설치. `acad.exe`, `accoreconsole.exe`, `acmgd.dll`, `acdbmgd.dll` 존재 | DXF 내보내기 입력 단계, 경로 B 로드 시험 |
| Revit | 2023, 2026 설치 | 이번 범위 밖 |
| LLM | 로컬 모델(Ollama) 없음. 외부 API 키 미보유 | 팀 결정 필요 |
| GitHub CLI | 미설치 | PR은 웹에서 생성 |

실행한 검증:

- `ezdxf`로 R2018 DXF를 새로 만들어 레이어 2개(`M-PIPE-CHW`, `M-DUCT-SA`), LINE·LWPOLYLINE·TEXT 3개 객체를 저장하고 다시 읽어 레이어별 객체 수를 정확히 회수했다. 경로 C의 입력 단계는 동작한다.
- `accoreconsole.exe`를 스크립트 모드로 실행해 프로세스 기동과 heartbeat 출력을 확인했다. 그러나 `SAVEAS`·`-DXFOUT` 스크립트로 파일이 생성되지 않았다. 헤드리스 도면 변환은 `미검증`이며, `/i` 옵션으로 입력 도면을 지정하는 방식은 아직 시험하지 않았다. 데모에서는 AutoCAD GUI에서 수동으로 DXF를 내보내는 방식으로 대체 가능하다.
- Windows 콘솔 기본 코드 페이지가 CP949라서 한글이 물음표로 깨지는 현상을 확인했다. 이슈 #7~#9 본문이 깨진 원인과 같다. 모든 스크립트와 출력 파일은 UTF-8로 명시 저장한다.

미검증:

- 외부 LLM API 호출(키 없음)
- Streamlit·Gradio 설치와 실행
- AutoLISP 로드와 AutoCAD 2024에서의 실제 실행
- 다른 팀원 PC 환경. 위 실측은 한 대의 PC 기준이다.

## 6. LLM 선택과 데이터 정책

| 선택지 | 장점 | 단점 | 데모 적합성 |
|---|---|---|---|
| 외부 상용 API | 설치 없음, 품질 높음, 구조화 출력 지원 | 키·비용·이용약관(SRC-001 Open API 조건) 확인 필요, 입력이 외부로 전송됨 | 합성 샘플만 전송한다는 전제로 적합 |
| 로컬 모델 | 데이터 외부 전송 없음 | 설치·GPU·품질 검증 시간 필요 | 하루 안에는 부담 |

권장(분석): 데모는 외부 API를 쓰되 합성 샘플만 전송하고, 제안서에는 "실제 도입 시 사내 배포 또는 온프레미스 모델로 전환"을 확장 단계로 적는다. API 키는 `.env`에 두고 커밋하지 않는다(`.gitignore`에 `.env` 등록 확인).

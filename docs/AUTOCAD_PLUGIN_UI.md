# AutoCAD 플러그인 UI 규칙 v0.2

기준 환경은 AutoCAD 2026의 어두운 작업 화면이다. 기본 WinForms 회색 팔레트 대신, CAD 화면을 가리지 않는 폭 약 420px의 4단계 세로 흐름을 사용한다. 밝은 테마 자동 전환과 실제 AutoCAD 호스트에서의 색·DPI 검증은 후속 확인이다.

## 패턴

| 구성 | 용도 | 상태 |
|---|---|---|
| 고정 헤더 | 제품명과 입력→해석→대상→승인 흐름 | 항상 보임 |
| 고정 상태 배너 | 녹음 저장·키 누락·전사 실패 등 즉시 피드백 | 정보 청록, 성공 녹색, 주의 갈색, 오류 적갈색 |
| 카드 01 | 로컬 녹음, 키 입력, 외부 전사, 수동 전사문 | 긴 전사문만 내부 스크롤 |
| 카드 02 | 이동량과 좌표계 확인 | 주요 버튼 청록 |
| 카드 03 | 후보 추천과 사람이 직접 대상 지정 | 추천은 절대 승인 아님 |
| 카드 04 | 승인 후 별도 실행 | 실행 버튼은 주의색 |

색상·타이포·버튼 상태의 단일 정의는 `autocad-plugin/Himec.AutoCad2026/PaletteTheme.cs`에 둔다. 본문은 Segoe UI 9pt, 제목은 10–12pt, 기본 글자 대비는 밝은 회색/어두운 표면으로 잡았다. 활성화되지 않은 버튼은 WinForms 기본 disabled 상태를 사용한다. 키 입력은 비밀번호 표시이며 이번 AutoCAD 실행 동안에만 메모리에 둔다.
토큰 기준 계산 대비비는 본문/표면 11.91:1, 보조 글자/표면 6.89:1, 청록 제목/표면 5.52:1, 주요 버튼 글자/배경 5.30:1이다. 실제 AutoCAD/DPI 렌더링과 비활성 버튼 대비는 호스트 화면에서 별도 확인한다.

키보드 순서는 녹음 → 키 설정 → 전사 → 전사문 → 분석 → 후보 → 직접 선택 → 승인 → 실행이다. API 전송과 최종 승인은 각각 별도 확인창을 요구한다. 상태 배너만으로 오류를 알리지 않고, 전사 실패는 모달 오류창도 띄운다. 색만으로 성공·실패를 구분하지 않고 문구를 함께 표시한다.

독립 미리보기 하네스는 420×640 및 420×1200 렌더링을 확인했다. 사용자별 번들 설치 후 AutoCAD 2026을 재시작하고 `HIMEC` 팔레트의 새 헤더·상단 상태·어두운 카드·WAV 선택·키 미설정 안내가 표시되는 것을 확인했다. 실제 호스트 캡처: [v0.2.1 팔레트](assets/autocad-palette-v0.2.1-host.png). 화면은 UI 표시 증거이며 API 호출이나 도면 이동의 성공 증거가 아니다. 키보드 순서·승인/실행 흐름과 다른 DPI는 추가 검증이 필요하다.

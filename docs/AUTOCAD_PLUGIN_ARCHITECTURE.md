# AutoCAD 플러그인 v0 설계 (2026-09-29)

## 요구와 제약

- 사용자는 AutoCAD 내부에서 녹음 시작/중지 → 변경 지시 확인 → 대상 지정 → 최종 실행을 원한다.
- 현재 PC에 AutoCAD 2026이 설치되어 있다. `kijun-0108`의 AutoCAD 2024 환경은 별도 빌드/검증 대상이다. Autodesk 공식 문서에 따르면 2024는 .NET Framework 4.8, 2026 초기 버전은 .NET 8을 대상으로 한다. 2026.1.2 이상에서는 .NET 10 권장이므로 정확한 설치 업데이트 수준을 실제 로드로 확인해야 한다.
- 2026-09-30 제출 목표이므로 모든 자연어·도면 유형을 자동 수정하지 않는다. 첫 버전은 로컬 녹음, 외부 전사 선택 호출, 검토 UI, 수동 객체 지정, 블록 이동 한 건이다.
- 실제 고객 도면/회의 내용의 외부 전송은 금지한다. 시연은 합성 자료만 사용한다. 녹음 동의는 사용자가 확보해야 한다.

## 구성과 데이터 흐름

```text
AutoCAD 2026 (.NET 플러그인)
  팔레트: 녹음/중지 → 전사문·변경 항목 편집 → 대상 직접 선택 → 승인 → 실행
  로컬 저장: WAV, 전사문, 변경 기록(사용자 PC, Git 외부)
  전사 어댑터: 명시적 호출 시 HTTPS API(OpenAI 우선 실험; 다른 제공자는 후속)
  CAD 실행기: 현재 DWG의 선택 블록 하나를 트랜잭션으로 이동

향후 선택적 원격 서비스: 자연어 지시 해석·후보 추천·버전 검사
  ↳ 승인/실행과 DWG 편집은 항상 로컬 플러그인
```

1. 버튼을 누르면 로컬 WAV로 녹음한다. 파일명에 시작 시각을 넣고 로컬 위치를 표시한다. 종료 시각 메타데이터는 아직 없다. 자동 업로드는 하지 않는다.
2. 사용자가 `전사`를 누르면 이번 AutoCAD 실행에만 입력한 키 또는 로컬 환경변수 키로 음성 전사 API를 호출한다. 키가 없거나 호출 실패 시 전사문을 직접 입력할 수 있다. 키 자체는 파일·Git에 저장하지 않는다.
3. 첫 버전은 이동 명령 하나만 정규화한다. `30cm`는 `300mm`로 변환한다. `왼쪽 세 번째`, `여기`, `저 기둥` 같은 표현은 AutoCAD 도면 좌표계/뷰/범위가 확정되지 않으므로 대상 미확정으로 남긴다.
4. 사용자가 전사문을 수정하고 도면에서 기둥 `BlockReference`를 직접 선택한다. 이동량은 전사문 재분석으로만 바뀐다. 도면·대상·이동량을 확인한 뒤 승인한다.
5. 실행 시 현재 도면 이름, mm 단위, 선택 객체 ID·핸들, 이동량, 승인 상태를 다시 검증한다. 실패하면 변경하지 않는다. 성공하면 단일 트랜잭션으로 적용하고 AutoCAD Undo로 되돌릴 수 있게 한다.

## 계약과 안전 경계

- 지시는 `source_text`, `action=move`, `target_handle`, `dx_mm`, `dy_mm`, `status`, `reviewed_at`을 가진다. 외부 모델 출력은 실행 명령이 아니라 제안이다.
- `target_handle`은 AutoCAD API에서 선택한 실제 객체만 확정한다. 모델이 만든 핸들·좌표를 그대로 실행하지 않는다.
- 블록 외 객체, 도면 불일치, 단위 불명, 둘 이상의 이동, 사용자 승인 누락은 실행 거절한다.
- 원본 도면은 플러그인이 자동 저장하지 않는다. 사용자가 Save/Undo를 통제한다. 로컬 회의 데이터는 사용자가 삭제할 수 있도록 기록 위치를 안내한다.

## 업데이트 방식

- [Autodesk의 플러그인 번들](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-Customization/files/GUID-BC76355D-682B-46ED-B9B7-66C95EEF2BD0.htm)로 설치 가능한 패키지를 만들고, 버전·호환 AutoCAD 릴리스를 표시한다. 새 DLL은 서명/신뢰 경로와 설치/재시작 절차를 거쳐 배포한다.
- 원격 AI 서비스/프롬프트는 API 버전을 유지하면 서버 배포로 모두에게 갱신할 수 있다. 그러나 설치된 DLL과 AutoCAD UI는 Vercel에 올렸다고 실시간 교체되지 않는다. 조용한 코드 다운로드·실행은 피한다.
- v0.2.1에는 AutoCAD 종료를 요구하고 기존 버전을 백업하는 사용자별 설치 스크립트를 준비했다. 시험 경로에서 교체·백업을 확인하고, 사용자 프로필 `ApplicationPlugins`에도 설치했다. 기존 미저장 시험 도면은 별도 DWG로 백업한 뒤 재시작했으며 새 팔레트 표시를 확인했다. 자동 업데이트는 아직 아니다.
- 장기적으로 업데이트 확인/다운로드 안내를 플러그인에 넣을 수 있지만, 사용자 승인과 롤백 가능한 버전 고정이 필요하다.

## 재검토할 결정

- 정확한 대상 AutoCAD 버전(2024/2026/둘 다), 2026 업데이트 수준, Windows 버전.
- 전사·추출 제공자와 회사 데이터 반출 정책, 모델 비용 상한.
- “왼쪽 세 번째”의 기준: 현재 화면/선택한 공간/그리드/층 중 무엇인지. 자동 타깃 확정은 이 기준을 먼저 정해야 한다.
- 멀티 도면 전파, 설비 간섭 검토, 실시간 전사, 자동 업데이트는 첫 버전 이후 독립 검증한다.

## 완료 기준

- 사이드카 예시에서 C1·B12·설비 영향 검토 대상 노드/연결을 생성하고 JSON 또는 그림으로 표시한다. 실제 도면에서 관계를 자동 추론했다고 주장하지 않는다.
- 시간 여유가 있으면 C1 이동 전후의 관계 표시를 생성한다. DXF 변경은 C 담당 코드만 수행하고 그래프 코드가 원본 도면을 건드리지 않는다.
- 입력·출력 예시, 실행 명령, 실제로 검증한 범위, 추정으로 남긴 관계를 PR에 기록한다.
- `main`·공통 문서·다른 담당 디렉터리를 수정하지 않는다. PR을 열고 병합하지 않는다.

## 목표

합성 도면·PDF·대본과 사이드카를 만들어 다른 팀원이 같은 입력으로 재현하게 한다. 담당: `kijun-0108`, 브랜치: `work/kijun-0108/r02` (팀장이 생성한 뒤 시작).

## 담당 파일

`prototype/samples/`, `prototype/sidecar/`만 편집한다. 공통 계약은 `prototype/CONTRACT.md`를 따른다.

## 완료 기준

- `A-101`, `A-301`, `E-201` 합성 DXF/PDF와 5문장 합성 대본을 만든다. C1은 A-101·A-301에 한 개씩 있다. 실제 고객 도면은 사용하지 않는다.
- 사이드카 생성 코드와 `sidecar_A-101.json` 형식의 재현 가능한 예시를 제공한다. PDF 좌표와 DXF 좌표의 관계를 어떻게 생성했는지 설명하고, 못 만들면 `pdf_rect_pt: null`로 둔다.
- 첫 산출물로 DXF 1장과 사이드카 1개를 빠르게 PR 또는 이슈 댓글로 공유한다. 다른 담당자의 출력을 기다리지 않는다.
- 실제 실행 명령, 생성된 파일, 환경 버전, 남은 미검증 사항을 PR에 적는다. AutoCAD 2024로 열어 봤다면 실제로 확인한 범위만 적는다.
- `main`·공통 문서·다른 담당 디렉터리를 수정하지 않는다. PR을 열고 병합하지 않는다.

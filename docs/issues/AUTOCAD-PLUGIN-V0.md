## 목표

사용자 요청에 따라 AutoCAD 안에서 회의를 녹음하고 변경 지시를 검토한 뒤, 사람의 명시적 승인 후 제한된 객체 이동을 실행하는 첫 플러그인을 만든다. 팀장 전용 브랜치에서 구현한다. 기존 Round 02의 합성 DXF/PDF 작업은 보존하고 계속 진행한다.

## 첫 버전 완료 기준

- AutoCAD 2026용 C# 팔레트에 녹음 시작·중지, 전사, 변경 항목 검토, 도면 객체 수동 선택, 실행 버튼이 있다.
- 녹음은 로컬 파일에만 저장한다. 외부 전사 호출은 사용자가 버튼을 누를 때만 하며 API 키는 로컬 환경변수에서 읽는다.
- “기둥을 위로 30cm” 같은 지시를 이동량 300mm로 정리하고, “왼쪽 세 번째” 같은 상대 위치는 자동 확정하지 않고 확인 필요로 남긴다.
- 객체 선택은 AutoCAD에서 사용자가 직접 클릭하는 경로를 우선 구현한다. 후보 자동 정렬·강조는 후속 작업이다.
- 실행 직전 현재 도면, 단위(mm), 선택 객체, 승인 상태를 재확인하고 지원하는 블록 이동 한 건만 트랜잭션으로 반영한다. 다른 작업은 실행하지 않는다.
- 빌드가 성공하고 플러그인 로드·녹음·실행 스모크 테스트 결과를 구분해 기록한다. 실제 AutoCAD 안에서 확인하지 못한 기능은 미검증으로 표시한다.

## 배포 결정

AutoCAD 플러그인 DLL은 사용자 PC에 설치/업데이트해야 한다. Vercel을 필수로 사용하지 않는다. 향후 AI 처리 서비스만 버전된 HTTPS API로 분리할 수 있으며, 도면 변경 실행과 승인 UI는 로컬 플러그인에 둔다. 원격 코드 자동실행/무단 DLL 교체는 하지 않는다.

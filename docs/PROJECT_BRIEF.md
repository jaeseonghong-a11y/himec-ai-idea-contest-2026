# 프로젝트 브리프

- 프로젝트명: 하이멕 AI 활용 아이디어 공모전
- 최종 갱신: 2026-09-29
- 마감 목표: 2026-09-30

## 1. 한 줄 정의

미정 — 핵심 사용자, 해결할 문제, AI의 역할을 한 문장으로 확정한다.

## 2. 사용자와 문제

- 주요 사용자: 미정
- 현재 작업 흐름과 불편: 미정
- 기존 도구로 충분하지 않은 이유: 미정
- 확인된 현장 근거: 미정

## 3. 첫 사용자 시나리오

미정 — 사용자의 입력부터 AI 처리, 검토·승인, 최종 결과까지 한 문단으로 작성한다.

## 4. 제품 및 제출 범위

- 핵심 기능: 미정
- AI가 담당하는 기능: 미정
- 사람이 최종 판단하는 지점: 미정
- AutoCAD/동반 앱/서버의 역할: 미정
- 데이터가 외부로 나가는 시점과 범위: 미정
- 공모 분야: 설계·엔지니어링 / 시공·품질관리 / 업무 혁신(공통) 중 선택
- 최종 제출물: 붙임 1~4 서류와 선택 첨부(PPT, 프로토타입, GitHub 주소, 기타)를 ZIP으로 이메일 제출
- 하지 않을 것: 미정

## 5. 성공 기준

- [ ] 공모전 공고의 필수 제출 항목과 형식을 모두 충족한다.
- [ ] 핵심 문제와 사용자 가치가 근거와 함께 설명된다.
- [ ] AI가 필요한 이유, 입력·출력, 사람의 검토 지점이 명확하다.
- [ ] 데모 또는 프로토타입의 최소 사용자 경로가 끝까지 동작한다.
- [ ] 발표/문서의 수치·인용·이미지 출처를 검증한다.
- [ ] 제출 직전 다른 팀원의 교차 검토를 통과한다.

# 녹음 객체 태그 — v0.3.1 개발 범위

## 지금 가능한 흐름

1. 녹음을 시작하고 팔레트의 **녹음 중 객체 태그**를 눌러 도면 객체를 클릭한다. 이때 녹음 시작 후 시각, 도면 이름, AutoCAD 객체 핸들·종류·레이어를 로컬 태그 세션에 기록한다. 태그 이름을 먼저 적으면 그 이름을 사용한다. 도면 자체는 바꾸지 않는다.
2. 녹음을 끝내면 태그 목록이 남는다. API 전사 또는 전사문 직접 입력 후 **전사문에서 객체 찾기**를 누르면 `C1`, `B12`, `기둥`, `덕트`, `배관`, `장비` 같은 제한된 언급을 목록에 추가한다. API 전사 성공 시에는 자동으로 이 추출을 실행한다. 이 행은 **미지정**으로 남으며, AI가 객체를 확정한 것으로 표시하지 않는다.
3. 목록에서 태그 이름을 직접 수정하거나 태그를 추가·삭제하고, 행을 선택해 **선택 태그에 객체 지정**으로 도면 객체를 클릭한다. 잘못 연결한 경우 **객체 연결 해제**를 사용할 수 있다. 상태와 지정/미지정 수가 보인다. 삭제는 확인창을 거친다.
4. 녹음 파일을 다시 선택하면 `%LOCALAPPDATA%\Himec\Sessions`의 해당 로컬 JSON 세션을 불러온다. 녹음·태그·발화 인용은 Git에 넣지 않는다. 서로 다른 녹음 파일의 태그를 섞지 않는다.

## 정확히 아직 안 되는 것

- **말하는 도중의 자동 음성 인식·자동 객체 연결은 없다.** 현재 전사는 녹음 종료 후 사용자 동의가 있을 때만 파일 단위로 호출한다. 녹음 중에는 사람이 객체를 직접 찍어 시간표시를 남길 수 있다.
- 전사 API의 현재 응답은 문장 단위 타임스탬프를 제공하지 않는다. 전사문에서 추출한 행의 시각은 `—`이다. 녹음 중 직접 찍은 행만 시각이 있다.
- 일반명사 `기둥`처럼 여러 후보가 있는 언급은 도면 객체와 자동 매칭하지 않는다. 대상은 사용자가 클릭해야 한다. 태그 핸들은 저장 당시의 참조이며, 나중에 도면 객체가 삭제되거나 바뀌었는지 재검증하는 기능은 아직 없다.
- 태그는 녹음 검토용 로컬 메타데이터다. AutoCAD 객체에 XData/속성을 쓰거나 화면에 영구 주석을 만들지 않는다. 변경 지시 승인/실행과 태그 목록은 현재 자동 연결되지 않는다.

## 검증 기준

- 순수 로직: 언급 추출, 중복 방지, 이름 수정 후 재추출, 객체 연결/해제·삭제를 합성 문장으로 검사한다.
- UI: 독립 팔레트 미리보기에서 5단계 배치와 태그 표를 확인한다.
- 실제 호스트: 새 버전을 AutoCAD 2026에서 로드하고, 합성 DXF 사본에서 녹음 중 객체 클릭→태그 세션 저장→녹음 후 목록 수정/재열기를 검사해야 한다. 이 검증이 끝나기 전에는 **호스트 기능 완료**라고 표기하지 않는다.
- 실시간 자동 음성 태그는 후속 설계에서 사용자 사전 동의, API 비용·지연, 정확한 발화 시각, 중복/모호성 처리, 오프라인 대안을 결정한 뒤 구현한다.

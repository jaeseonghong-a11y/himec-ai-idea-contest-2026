# 제출 체크리스트

## 공식 요건

- [ ] 접수일이 2026-09-30을 넘지 않음
- [ ] 공모 분야가 명확함
- [ ] 개인·기업 또는 5인 이하 팀 요건 충족
- [ ] 붙임 1 참가신청서 작성·서명
- [ ] 붙임 2 참가서약서 팀원 전원 작성·서명
- [ ] 붙임 3 개인정보 동의서 작성·서명
- [ ] 붙임 4 출품작 작성
- [ ] 선택 첨부(PPT, 프로토타입, GitHub 주소 등) 포함 여부 확인
- [ ] 분야별 복수지원 시 서류를 각각 분리
- [ ] ZIP 이름을 `HIMEC AI 활용 아이디어 공모전_(팀명)` 형식으로 지정
- [ ] `contest@himec.co.kr` 수신 주소 재확인

## 내용·권리 검토

- [ ] 타 공모전 수상·상용화·중복 제출 여부 확인
- [ ] 그림·사진·아이콘·폰트·코드·데이터 사용권과 출처 확인
- [ ] Open API 약관의 개발·배포·상용화 조건 확인
- [ ] 공개 전 지식재산권 보호 필요성 결정
- [ ] 제안서의 수치·인용·제품 기능을 원출처와 대조
- [ ] 고객 도면·개인정보·기밀이 산출물과 Git 이력에 없는지 확인

## 최종 패키지 검증

- [ ] 모든 문서가 열리고 글꼴·표·이미지가 깨지지 않음
- [ ] 팀명·작품명·분야·참가자 정보가 문서마다 일치
- [ ] GitHub 링크를 제출한다면 심사자가 접근 가능한 공개 범위를 결정
- [ ] ZIP을 새 폴더에 풀어 누락·중복 파일 확인
- [ ] ZIP SHA-256과 최종 파일 목록 기록
- [ ] 이메일 제목·본문·첨부를 팀 대표가 최종 확인
- [ ] 전송 완료 시각과 수신/접수 확인을 `CURRENT_STATE.md`에는 개인정보 없이 기록

정확한 마감 시각은 공식 공고에 없으므로 마지막 날 늦은 제출을 피한다. 실제 이메일 전송과 개인정보 동의는 팀 대표가 수행한다.

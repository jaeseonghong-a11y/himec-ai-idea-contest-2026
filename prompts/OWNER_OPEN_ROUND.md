# 팀장 AI 작업 라운드 시작 요청문

아래 코드블록 내부를 수정하지 말고 팀장이 사용하는 AI에 그대로 붙여넣는다.

```text
이 저장소의 팀장 통합형 협업 라운드를 안전하게 시작해줘.

AGENTS.md, START_HERE.md, BRANCH_ASSIGNMENTS.md, CURRENT_STATE.md, docs/TEAM_WORKFLOW.md와 현재 git status/diff/log, GitHub collaborator·초대·이슈·PR 상태를 먼저 확인해.

저장소 소유자 jaeseonghong-a11y만 main 통합 담당이다. 다른 팀원의 기존 브랜치, PR, 미커밋 작업을 삭제하거나 덮어쓰지 마.

열린 팀원 PR이 있으면 새 라운드를 만들지 말고 상태와 먼저 처리할 순서를 알려줘. 열린 팀원 PR이 없고 현재 라운드가 종료된 것이 확인되면 origin/main을 fast-forward로 최신화하고, 아직 사용하지 않은 다음 rNN 번호를 계산해 최신 origin/main에서 아래 팀원별 새 원격 브랜치를 만들어:
- work/archuni/rNN
- work/ehgudwns18/rNN
- work/kijun-0108/rNN

기존 브랜치 이름을 삭제 후 재사용하거나 force push하지 마. BRANCH_ASSIGNMENTS.md에 새 라운드, 정확한 브랜치, 배정 이슈, 담당 경로를 기록해. 이슈 배정이나 담당 경로가 정해지지 않았다면 임의로 결정하지 말고 필요한 결정만 나에게 질문해.

문서 변경은 팀장 전용 브랜치와 PR로 기록하고 안전하게 main에 통합한 뒤, 새 팀원 브랜치가 그 최신 main에서 생성됐는지 각각 SHA로 검증해.

마지막에는 main SHA, 라운드 번호, 팀원별 브랜치와 이슈, 초대 수락 상태, 남은 결정을 알려줘.
```

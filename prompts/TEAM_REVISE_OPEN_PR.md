# 팀원 AI 열린 PR 수정 요청문

팀장 리뷰를 받고 같은 PR을 고쳐야 할 때 아래 코드블록을 그대로 붙여넣는다.

```text
HIMEC 공모전 저장소에서 내 열린 PR의 리뷰 의견을 확인하고 내 담당 범위에서 수정해줘. GitHub 로그인 사용자명, 최신 origin/main의 BRANCH_ASSIGNMENTS.md, 내 브랜치·PR·이슈, 최신 리뷰 댓글과 checks를 확인해.

PR이 이미 MERGED이거나 닫혔다면 기존 브랜치에 새 변경을 push하지 말고 상태와 필요한 다음 조치를 알려줘. 열려 있다면 기존 할당 브랜치에서만 작업하고, 다른 사람의 미커밋 파일을 보존해.

리뷰 의견과 실제 코드·문서를 대조해 안전하게 고칠 수 있는 항목을 수정하고 관련 검증을 다시 실행해. 제품 방향이나 충돌 해결 방식이 불명확하면 추측해 바꾸지 말고 팀장에게 질문할 항목을 정리해. 내 변경만 commit·push해 같은 PR을 갱신하고, 새 PR이나 새 브랜치를 만들지 마.

PR 설명에 수정 사항과 검증 결과를 반영하고 팀장에게 재검토를 요청하는 댓글을 한 번만 남겨. main을 수정·push·merge하거나 force push하지 마. 마지막에는 PR URL, 최신 head SHA, 해결한 의견, 남은 쟁점을 알려줘.
```

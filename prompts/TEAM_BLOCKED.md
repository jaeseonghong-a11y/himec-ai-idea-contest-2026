# 팀원 AI 작업 중 막혔을 때 요청문

권한, 인증, 충돌, 환경 문제로 진행이 멈췄을 때 아래 코드블록을 그대로 붙여넣는다.

```text
HIMEC 공모전 저장소에서 내 작업이 막힌 원인을 확인해줘. 저장소 위치, GitHub 로그인 계정, git status, 현재 브랜치, origin/main의 BRANCH_ASSIGNMENTS.md, 내 할당 이슈·PR과 최근 오류를 확인해.

내 계정 권한, 지정 브랜치 존재 여부, 미커밋 변경, 원격과 로컬 이력, 충돌 파일, 필요한 도구·라이선스를 구분해 원인을 찾아. 내 파일을 잃지 않는 되돌릴 수 있는 조치라면 수행하고 실제로 해결됐는지 검증해. 비밀번호·토큰을 채팅에 붙여넣으라고 요구하지 마.

팀장 결정, 새로운 권한, 다른 팀원 변경, 제품 방향 판단이 필요하면 그 부분은 임의로 처리하지 말고 팀장에게 전달할 정확한 상황과 필요한 조치 한 가지를 적어줘. main 수정·push·merge, force push, reset, stash, 다른 팀원의 파일 삭제는 하지 마.

마지막에는 원인, 이미 확인한 사실, 안전하게 해결한 것, 남은 차단점, 팀장에게 보낼 한 문장 요청을 알려줘.
```

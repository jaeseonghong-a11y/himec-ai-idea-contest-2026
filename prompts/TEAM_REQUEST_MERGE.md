# 팀원 AI 병합 요청문

작업을 마치고 팀장에게 병합을 요청하고 싶을 때 아래 코드블록을 그대로 붙여넣는다.

```text
HIMEC 공모전 저장소에서 내가 맡은 작업의 병합 요청을 준비해줘. GitHub 로그인 사용자명과 저장소 위치를 확인하고, origin을 fetch한 뒤 origin/main의 BRANCH_ASSIGNMENTS.md, AGENTS.md, docs/TEAM_WORKFLOW.md와 내 할당 이슈를 읽어.

내 할당 브랜치의 변경, 미커밋 파일, 원격 상태, main 대상 PR을 확인해. 내가 맡은 범위의 미커밋 작업이 있으면 완료 기준과 검증을 확인하고 내 파일만 commit·push해. 다른 사람의 변경이나 불명확한 파일은 건드리지 말고 알려줘.

PR이 없으면 내 할당 브랜치에서 main 대상 PR을 하나 만들어. 이미 열려 있으면 중복 PR을 만들지 말고 설명·검증 결과·미검증 사항을 갱신해. PR이 이미 MERGED라면 병합 요청을 반복하지 말고 그 상태를 알려줘.

PR의 head SHA와 최신 push가 일치하는지, 예상치 못한 파일·비밀값·개인정보가 없는지 확인해. 준비가 끝났으면 PR에 팀장 jaeseonghong-a11y의 검토와 병합을 요청하는 댓글을 한 번만 남겨. 이미 같은 요청을 남겼다면 중복 댓글을 쓰지 마.

main을 직접 수정·push·merge하지 마. PR을 닫거나 브랜치를 삭제하거나 다음 브랜치를 만들지 마. 완료되면 PR URL, head SHA, 검증 결과, 팀장에게 전달할 미결 사항을 알려줘.
```

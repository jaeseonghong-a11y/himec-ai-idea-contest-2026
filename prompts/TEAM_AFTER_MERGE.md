# 팀원 AI 병합 후 새 작업 요청문

내 PR이 병합됐고 다음 작업을 시작하고 싶을 때 아래 코드블록을 그대로 붙여넣는다.

```text
HIMEC 공모전 저장소에서 내 이전 PR의 병합 상태를 확인하고, 새 작업이 배정됐다면 시작해줘. 현재 GitHub 로그인 사용자명과 저장소를 확인하고 origin을 fetch해. AGENTS.md, START_HERE.md, docs/TEAM_WORKFLOW.md와 최신 origin/main의 BRANCH_ASSIGNMENTS.md를 읽어.

내 이전 PR이 실제 MERGED인지 GitHub에서 확인해. 아직 열려 있으면 기존 PR과 브랜치를 유지하고 팀장 검토를 기다려. 병합됐더라도 내가 새 브랜치를 직접 만들지는 마.

최신 배정표와 내게 배정된 열린 이슈를 확인해. 이전 브랜치와 다른, 팀장 AI가 이미 만든 새 원격 `work/내사용자명/rNN` 브랜치와 담당 이슈가 모두 있으면 해당 브랜치만 checkout·fast-forward하고, 담당 이슈의 완료 기준과 파일 범위를 읽어 작업·검증·commit·push해. main 대상 PR을 하나 열고 병합하지 말고 멈춰.

새 브랜치나 이슈가 없으면 병합된 PR에 팀장 jaeseonghong-a11y에게 다음 작업·새 브랜치 배정을 요청하는 댓글을 한 번만 남기고 멈춰. 이미 요청했다면 중복 댓글을 쓰지 마. 다른 팀원의 브랜치나 main을 수정하지 마.

마지막에는 이전 PR 상태, 새 브랜치·이슈 유무, 작업했다면 새 PR URL·검증 결과, 배정 대기라면 팀장에게 필요한 결정을 알려줘.
```

# AutoCAD 2026 합성 도면 스모크 테스트

`three_columns_mm.dxf`는 실제 설계 자료가 아닌 시험 도면이다. X=0, 1000, 2000 mm, Y=0 mm에 같은 `COLUMN` 블록 3개가 있다. 재생성: `python autocad-plugin/tests/make_smoke_dxf.py`.

1. AutoCAD에서 이 DXF를 연다. 현재 다른 작업 도면은 저장 여부를 먼저 확인한다. 필요하면 `ZOOM` → `E`로 전체를 본다.
2. `HIMEC` 팔레트의 전사문에 `왼쪽에서 세번째 이 기둥을 위로 30CM위로 옮기자`를 넣고 `전사문에서 이동 지시 찾기`를 누른다. X 0 / Y +300 mm인지 확인한다.
3. `‘왼쪽 세 번째’ 후보 찾기`를 눌러 오른쪽 끝 세 번째 `COLUMN`의 핸들이 추천되는지 확인한다. **추천은 확정이 아니다.**
4. `도면에서 대상 직접 선택`을 누르고 오른쪽 끝 `COLUMN` 사각형을 클릭한다. 팔레트에 선택 핸들이 표시되는지 확인한다.
5. `지시 승인`의 확인창에서 도면·핸들·X 0 / Y +300 mm를 읽고 승인한다. 그다음에만 `승인된 변경 실행`을 누른다.
6. 오른쪽 끝 사각형이 Y=0 → Y=300 mm로 이동했는지 확인한다. AutoCAD `UNDO`로 원래 위치에 돌아오는지도 확인한다. 시험 도면을 실제 프로젝트 도면에 덮어쓰지 않는다.

어느 단계든 다르게 보이면 **다음 버튼을 누르지 말고** 화면과 명령창 메시지를 공유한다. 녹음/API 전사는 별도 시험이며, 실제 회의나 고객 정보는 사용하지 않는다.
